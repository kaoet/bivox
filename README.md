# kaols — 超低延迟实时语音识别 / 语音合成（Windows GUI）

基于阿里云百炼 **Qwen-Audio** 的实时语音识别（ASR）与语音合成（TTS）桌面客户端，面向实时对话、VRChat 等低延迟场景。

全双工流式流水线：麦克风采集 → 流式 ASR → 按标点/语义分块 → 流式 TTS → 平滑播放，无需等整句说完。

- 纯 GUI（egui/eframe），**便携模式**：配置、缓存、日志都在 exe 同目录，整个文件夹拷走即用；
- **单实例**：同一目录只允许开一个窗口，重复启动会激活已有窗口；
- 本地 **Silero VAD** 门控（ONNX 模型随 exe 内嵌，不额外分发文件）、实时字幕（语言代码 + TTS 进度分色）、多语言自定义（复刻）音色；
- 可选 VRChat OSC 聊天框输出：把实时字幕（可含译文）同步到 VRChat 的 ChatBox。

**系统要求**：Windows 10/11 x64、可用的百炼 API Key、联网。发布包不含安装器，解压即用；ONNX Runtime 已静态链接进 exe，无需安装额外运行库。

## 快速开始

1. 解压发布包（`kaols.exe` + `README.md` + `THIRD_PARTY_NOTICES.md`）到一个**可写目录**（例如 `D:\Apps\kaols`）；
2. 双击 `kaols.exe`：首次启动会在 exe 同目录生成 `config.toml`，并自动落在「设置」页；
3. 在「设置」页填入百炼 API Key（[控制台](https://bailian.console.aliyun.com/)），点「保存 API Key」；
4. 回到「实时」页点「开始」，对着麦克风说话即可看到字幕并听到合成语音。

> 单实例行为：第二次启动会尝试把已有窗口恢复到前台并退出，不会抢麦克风。
> 不同目录的两份便携副本可以同时运行。

### 便携目录

```text
kaols.exe
config.toml            # 首次启动生成；含 API Key，注意保密
config.toml.bak        # 每次在 GUI 中写回配置前的备份
cache.json             # 音色复刻 + ASR 预编译热词缓存（模型/音频指纹 → voice_id；ASR 模型 → vocabulary_id）
logs\kaols-YYYY-MM-DD.log  # 按天日志，保留最近 7 天
crash.log              # 崩溃信息（如有）
```

程序只读 **exe 所在目录**的 `config.toml`，不读 `%APPDATA%`、当前工作目录或环境变量。
配置里的相对路径（缓存、样例音频）以 `config.toml` 所在目录为基准。

### 当前音色

「语音合成」页顶部 Radio 二选一，未选中的一侧控件禁用：

- **现有音色**：输入框，填内置音色名（如 `qiaoxiaojiao_v3.1`）或任意百炼 voice_id；
- **自定义音色**：下拉选择 `[tts.custom_voices]` 里的条目（写入 `custom:<键名>`）。

改动后点页面右上角 **保存** 一次写回 `config.toml`；**放弃更改** 同时还原当前音色与下方音色编辑草稿。
运行中保存会按「配置热更新」自动用新配置重启实时管线。

内置音色没有可按模型查询的列表 API（官方只有文档表：[Qwen-Audio-TTS 音色列表](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-voice-list)），因此用输入框填写 voice id。

### 中文方言

「语音合成」页「当前音色」下方有 **中文方言** 下拉，默认 **普通话**：

- 只影响**判定为中文**的句子：选方言后合成请求会附带 `instruction`「请讲<方言>。」；普通话不附加任何方言指令（默认音色行为不变）。
- 官方支持 **20 种**中文方言：广东话、重庆话、东北话、甘肃话、贵州话、浙江话、河北话、河南话、湖北话、湖南话、江西话、宁波话、宁夏话、青岛话、陕西话、山西话、山东话、上海话、四川话、云南话。
- 实际能否念出方言取决于**音色**：复刻音色支持全部 20 种；`qwen-audio-3.1-tts-flash` 的 4 个多语种/方言系统音色（`longanhuan_v3.1`、`longanlingxin_v3.1`、`longanfengyue_v3.1`、`xunanchuan_v3.1`）仅支持上海、广东、东北、重庆、陕西、云南、宁波、甘肃 8 种；其余精品中文系统音色以普通话为主。
- 方言与音色、语言列表正交，也不会改变合成的 `language_hints`；非中文句子忽略方言。
- 改方言后点页面右上角 **保存** 写回 `[tts] dialect`；运行中保存会按「配置热更新」自动重启实时管线。

### 语音识别与热词

「语音识别」页集中编辑 `[asr]` 的三组字段：**识别模型**、**语言列表**、**预编译热词**。

- **识别模型**：可编辑，右侧「恢复默认」填回内置默认模型；换模型会重建对应的预编译热词列表。
- **语言列表**：有序，第一个是默认语言；拖动每行左侧的「≡」手柄调整顺序，用「删除」移除、用「添加语言」追加。超过 4 种时页面提示：ASR 接口只使用前 4 个作为 `language_hints`，本地语言判定仍使用完整列表。
- **预编译热词**：多行输入框，**一行一个词条**（例如人名、产品名、行业术语）；保存时去空白、去空行、去重保序。热词权重固定为 **50**（百炼「超级热词」档位，实测召回更好）、不限定语种，不需要写 `lang` 或权重；用于百炼**预编译热词**（不是即时热词）。
- 页右上角「保存 / 放弃更改」一次写回 `[asr]` 的 `model` / `languages` / `hotwords`；运行中保存会按「配置热更新」自动重启实时管线，当前句会丢失。
- `[vad]` / `[chunking]` 仍只读，需手改配置后点「设置 → 重新加载配置」。

热词与百炼的同步时机：

- **开始会话时**自动同步：首次为当前 ASR 模型创建预编译热词列表，拿到的 `vocabulary_id` 立即写入 `cache.json`；之后启动会复用，热词有变化时更新该列表。
- 修改热词后要**重新开始会话**才会上传；点「保存」只写回配置，不会立刻访问百炼。
- 百炼建议两次热词更新至少间隔 **5 分钟**；太频繁时本次沿用旧词表，界面顶部显示黄色「运行告警」，下次开始会话会自动重试。
- 同步失败（例如使用**子业务空间**、网络异常）不阻断会话：降级为不带热词识别，并显示黄色「运行告警」，见「故障排查」。
- 限制（百炼侧）：仅**主业务空间**支持热词；每账号最多 **50** 个列表；因为固定使用超级热词权重 50，每个列表最多 **50** 条；单条热词含非 ASCII 字符时 ≤**15** 个字符（空格计入），纯 ASCII 时 ≤**7** 个空格分隔片段。
- 首次创建列表可能让「启动中」持续**几十秒**（等待百炼部署就绪）；就绪前本次识别暂不使用热词，下次开始会话会继续等待。
- 删除 `cache.json` 会导致下次重新创建热词列表（同时重新复刻音色）。

### 实时页打字输入

「实时」页字幕列表下方有一个输入框（支持多行，**Shift+Enter** 换行）：输入文字后按 **Enter** 或点「朗读」，程序会用当前音色把这段文字读出来。

- 仅「运行中」时可提交；未开始时可以先输入，提交时会提示先点「开始」。
- 单次输入上限 **500 字符**；空白不会提交。
- 输入框默认 1 行，内容变多时向上长高，约 **4 行封顶**后在框内滚动，不会一直挤压字幕区。
- 朗读是**排队**的：当前已排队/正在播放的音频会照常播完，你输入的句子排在后面依次朗读，不会打断正在播放的声音。
- 语言沿用当前对话的语言判定（例如一直在用日语交流，输入“东京”仍按日语读）。
- 如果提交时实时识别的那一句还没结束，该句只保留已经送去合成的前缀进字幕，剩余识别内容不会补读。
- 每句输入都会出现在字幕历史里（不区分是打字还是语音）。

### 翻译模式

在「翻译」页勾选 **启用翻译模式**，并选好 **目标语言**：之后无论麦克风说话还是底部打字输入，都会先翻译成目标语言，再**合成目标语言的语音**，字幕显示「译文大字行 + 原文小字行」。

- 目标语言限 TTS 支持的 **16 种**：`zh en fr de ja ko ru pt th id vi es it ms fil ar`。
- **翻译粒度**：`标点即翻` 延迟低、句子可能偏碎；`整句再翻` 等一句话说完再翻，质量更好但延迟约一整句。
- 字幕默认同时显示原文与译文，两行**各自有复制按钮**（悬停该行右端出现）；关掉「字幕同时显示原文」只显示译文。
- 运行中修改开关 / 目标语言 / 粒度会**自动重启实时管线**，当前句会丢失；「显示原文」只影响渲染，改后立即生效、不重启。
- 自定义音色若没有目标语言的声线样本，会按内置回退规则用默认样本合成。
- 翻译是逐段发起的 HTTP 请求，需要联网与 API Key；翻译失败会显示红色错误条。

### VRChat 聊天框（OSC）

在「VRChat」页勾选 **启用 OSC 聊天框** 后，实时字幕会同步到本机 VRChat 的 ChatBox。使用前需要：

1. 在 VRChat 中开启 OSC：**Action Menu → Options → OSC → Enabled**；
2. 打开 VRChat 设置里的 **Show Own ChatBox**（否则看不到自己的聊天框）；
3. 确认「发送端口」与 VRChat 的 OSC 接收端口一致（默认 **9000**；若启动参数改过 `--osc=inPort:senderIP:outPort`，填相同的 `inPort`）。

行为说明：

- 文本**最多 1 秒更新一次**（VRChat 聊天框实测上限；发送更快会跳字，持续过快可能触发临时禁言），GUI 字幕本身仍是实时的；
- 翻译模式未开启时固定显示 ASR 原文；开启后按所选模式显示原文/译文/双语（双语为「译文\n原文」）；双语默认按**软 5:4**分配（译文 5 个显示行/约 5/9 字符，原文 4 行/其余；任一侧用不完会借给对方，总行数不超过 9）；
- 超长文本按 144 字符 / 9 行截断，**保留句尾**（前导 `…`）；这里的 9 行包含自动换行，默认 UI 下约每行 24 个 ASCII / 15 个中文 / 12 个 emoji；
- 当前句显示时自动打开 VRChat 的 typing 指示器，句终/清空时关闭；
- 正常句终后最后文本由 VRChat 约 **30 秒**自然消失；停止会话、关闭 OSC 或关窗会立即清空；
- 「发送测试消息」会立即发一条固定文本，便于确认链路（不走 1 秒节流）。

> 注意：聊天框内容会被附近玩家看到；建议在私人世界测试，并留意说话内容的隐私。

## 配置说明

`config.toml` 首次启动自动生成，**完整注释见文件本身**。常用字段：

```toml
[api]
key = "sk-..."                 # 必填
# workspace_host = "ws-xxxx.cn-beijing.maas.aliyuncs.com"  # 业务空间专属域名（纯 host）

[asr]
# model = "qwen-audio-3.1-asr-flash-streaming"
languages = ["zh", "ja"]       # 有序；只写一个 = 强提示该语言；整份列表作为 ASR 提示
# hotwords = ["原神", "崩坏：星穹铁道"]   # 预编译热词数组（GUI 中一行一个）；权重固定 50（超级热词），不写语种/权重

[tts]
# model = "qwen-audio-3.1-tts-flash"
voice = "qiaoxiaojiao_v3.1"    # 系统音色名 / 复刻 voice_id / custom:<键名>
# dialect = "普通话"            # 中文方言（仅中文句子生效；官方 20 种方言之一）

[cache]
# file = "cache.json"          # 音色复刻 + ASR 预编译热词缓存（相对配置文件目录）

[audio]
# input_device = "Microphone (USB Audio)"
# output_device = "CABLE Input (VB-Audio Virtual Cable)"   # 不填 = 系统默认

[vad]
enabled = true                 # 只上传语音段，省 ASR 费用（Silero 神经网络 VAD）
threshold = 0.5                # 起音概率阈值（0–1，越大越不敏感）
min_silence_ms = 500           # 低于负阈值（threshold-0.15）持续该时长判定说完
tail_ms = 1000                 # 句末补发静音，触发服务端 sentence_end

[chunking]
words = 6                      # 投机分块阈值

[translate]
# enabled = false              # 翻译模式开关（也可在「翻译」页勾选）
# target = "en"                # 目标语言，16 种 TTS 语言之一
# model = "qwen-mt-flash"      # 只读：换模型需手改这里后「重新加载配置」
# granularity = "clause"       # clause = 标点即翻；sentence = 整句再翻
# show_source = true           # 字幕是否显示原文行（关掉只显示译文）

[vrchat.osc]
# enabled = false             # VRChat OSC 聊天框开关（也可在「VRChat」页勾选）
# port = 9000                 # VRChat 的 OSC 接收端口
# display = "bilingual"       # source / bilingual / translation（仅翻译模式生效）
```

- `[api] workspace_host` 只填**纯 host**，不要带 `wss://`、路径或端口；省略该字段则使用百炼通用域名。
- `[audio]` 设备名按**完整名称精确匹配**：设备改名/被拔掉会明确报错，不会静默回退到默认设备。
- `[vad] debug = true` 可打印每个 chunk 的 Silero 概率、阈值与发送决策（仅排障用）；本地 VAD 不需要按麦克风/房间标定。
- `[translate]` 的 `enabled` / `target` / `granularity` / `show_source` 也可在「翻译」页直接修改；`model` 只读。
- `[vrchat.osc]` 的 `enabled` / `port` / `display` 也可在「VRChat」页直接修改；该段不进配置指纹，改设置不重启实时管线，文本固定 1 秒更新一次。
- `[cache] file` 默认 `cache.json`（相对配置文件目录），同时保存音色复刻记录与 ASR 预编译热词的 `vocabulary_id`；删除它会导致下次重新复刻音色、重建热词列表。
- `[asr]` 的 `model` / `languages` / `hotwords` 可在「语音识别」页编辑；`[tts] model`、`[translate] model`、`[vad]`、`[chunking]` 等其余字段仍需手改配置，改后点「设置 → 重新加载配置」。

### 支持的语言

`[asr] languages` 使用 ASR 语言代码（30 种）：

```text
zh en ja ko vi th id ms tl hi ar fr de es pt ru it nl sv da fi no el pl cs hu ro bg hr sk
```

自定义音色样本的 `language` 使用**声音复刻**语言代码（16 种）：

```text
zh en fr de ja ko ru pt th id vi es it ms fil ar
```

- ASR 的 `tl`（菲律宾语）在复刻侧自动按 `fil` 处理；
- 翻译模式的 `[translate] target` 使用同一份复刻语言表（16 种），因此目标语言的语音一定有对应声线可选；
- 常见非中英语种（ja/ko/fr/de/ru/es/pt/it/th/vi/id/ms/fil/ar）合成时会附带内置语种指令；不在复刻语言列表内的语言合成时按 `other` 处理，自定义音色会回退到默认声线；
- 列表顺序有意义：第一个是默认语言，本地判定也以完整列表为范围。

中文方言（`[tts] dialect`，默认普通话）使用**官方方言名**：

```text
普通话 广东话 重庆话 东北话 甘肃话 贵州话 浙江话 河北话 河南话 湖北话 湖南话
江西话 宁波话 宁夏话 青岛话 陕西话 山西话 山东话 上海话 四川话 云南话
```

- 只认上表写法（官方写作「广东话」，不支持「粤语」等别名），配置写错会在启动/保存时明确报错；
- 方言只对判定为中文的句子生效，通过 `instruction` 传递，不进入 `language_hints`；非中文句子忽略方言。

## 自定义（复刻）音色

一个音色可以有多份不同语言的声线样本，合成时按本句判定的语言选样本（缺该语言回退第一个样本）：

```toml
[tts.custom_voices.edgar]
name = "异环 - 埃德嘉"

[[tts.custom_voices.edgar.samples]]
language = "zh"
audio = "samples/edgar-zh.wav"
rate = 1.0                     # 可选合成语速，默认 1.0，范围 0.5–2.0

[[tts.custom_voices.edgar.samples]]
language = "ja"
audio = "samples/edgar-ja.wav"
rate = 1.0
```

- 样本音频：清晰单人、≥5 秒（推荐 10–20 秒，单条建议 ≤60 秒）、≤10 MB，支持 wav/mp3/m4a；复刻时**只取前 20 秒**（百炼 `max_prompt_audio_length`），更长的部分不会被使用；
- `rate` 是**样本级**语速（同一音色不同语言的声线可不同）：默认 `1.0`，范围 `0.5`–`2.0`；合成时用本句语言所选样本的语速，缺该语言回退第一个样本时用该样本的语速；内置音色/普通 voice_id 固定 `1.0`；
- GUI 每个样本有「语速」滑条（步长 0.05）与「重置」（恢复默认 1.0×），随「保存」一起写回；运行中保存会按「配置热更新」自动重启实时管线；
- 语速不参与复刻/缓存：改 `rate` 不会重新上传或复刻样例音频；
- 每个样本按（TTS 模型, 音频内容指纹）复刻一次并写入 `cache.json`，重复启动不会重复上传；
- 删除 `cache.json` 只会导致下次重新复刻；同一段音频在不同 TTS 模型下分别缓存；
- 若百炼账号里的复刻音色被删除，下次开始会话时会自动检测并重新复刻，一般无需手工处理缓存；
- GUI 保存会整体重写 `[tts.custom_voices]`（**表内注释不保留**），写前校验并备份 `config.toml.bak`；
- GUI 选音频时：文件在程序目录内则保存相对路径，目录外则保存绝对路径（可能影响便携性，界面会提示）。

## 故障排查

- **启动提示未配置 API Key**：在「设置」页填写后保存，或编辑 `config.toml` 的 `[api] key` 后点「重新加载配置」。
- **设备打不开/找不到**：到「音频」页重新选择设备（完整名称会保存到配置）；设备改名或被拔掉时不会自动回退默认设备。
- **说话没反应 / 顶栏 VAD 不亮**：确认麦克风有输入；本地 VAD 是 Silero 概率门控（默认阈值 0.5），轻声一般也能触发，环境噪声很大时可尝试 `[vad] threshold = 0.45`；`[vad] debug = true` 可看每个 chunk 的概率。
- **顶部黄色「运行告警」提示本地 VAD 推理失败**：已降级为全量上传（识别不受影响，但会增加 ASR 费用）；停止后重新开始会话可重试；持续复现请附日志反馈。
- **连接/鉴权失败**：检查 Key 是否有效、`[api] workspace_host` 是否填对（业务空间专属域名只填 host）；底部日志面板有服务端错误码。
- **GPU 初始化失败 / 远程桌面黑屏**：发布版默认使用 wgpu（DX12）；可从源码用 `renderer-glow`（OpenGL）变体构建兜底，构建方式见 `CONTRIBUTING.md`。
- **自定义音色失败**：检查样例音频路径、时长/大小/格式，以及账号下音色是否仍存在；日志里会标出是哪一步失败。
- **方言没生效**：确认本句判定为中文、且所选音色支持方言指令（复刻音色支持全部 20 种；系统音色仅上述 4 个多语种/方言音色支持 8 种）；运行中改方言需点「保存」触发自动重启。
- **热词没生效 / 顶部显示黄色「运行告警」**：预编译热词仅**主业务空间**支持，确认没有使用子业务空间，并检查网络与 API Key；百炼建议两次热词更新间隔 ≥5 分钟，太频繁时本次沿用旧词表、下次开始会话自动重试；改完热词要**重新开始会话**才会上传；底部日志里能看到具体的同步错误。
- **VRChat 聊天框不显示**：确认 VRChat 中 OSC 已开启、`Show Own ChatBox` 已开、kaols 的发送端口与 VRChat 接收端口一致；可用「发送测试消息」快速确认链路；VRChat 未运行时不会报错（UDP 无连接）。
- **VRChat 聊天框偶尔跳字**：VRChat 侧对 ChatBox 有约 1 条/秒的更新上限，kaols 已按 1 秒节流；如果仍出现，检查是否有其它 OSC 程序同时占用/写聊天框。
- **启动中停留几十秒**：首次创建预编译热词列表需要等百炼部署就绪，通常会自行进入就绪状态；就绪前本次识别暂不带热词，下次开始会话会继续等待。
- **日志与崩溃**：底部日志面板与 `logs\` 目录；崩溃信息见 `crash.log` 和界面顶部红色错误条。
- **双击没反应**：可能已有实例在运行（会尝试激活已有窗口）；也检查程序是否被安全软件拦截。

## 安全提示

- `config.toml` 里是**明文 API Key**；不要把整个程序目录发给别人，发布 zip 里不含它；
- 备份/分享目录等于分享 Key 与缓存（音色复刻、ASR 预编译热词），请自行评估风险；
- 所有可写文件都在 exe 同目录，不需要管理员权限；建议放在可写目录（如 `D:\Apps\kaols`）。
